# Yandex Disk Sync

Консольная программа для односторонней синхронизации файлов из локальной папки с резервной папкой на Яндекс Диске.

## Возможности

- Первая синхронизация сразу после запуска.
- Загрузка новых локальных файлов.
- Обновление файлов, изменённых локально.
- Удаление из облачной папки файлов, удалённых локально.
- Периодическая проверка локальной папки.
- Журналирование событий в файл и консоль.
- Обработка сетевых ошибок и ошибок отдельных файлов без остановки основного цикла.
- Проверка изменений содержимого файлов с использованием MD5 и размера, если эти проверки реализованы в текущей версии кода.

Синхронизируются только файлы непосредственно в выбранной папке. Вложенные директории не синхронизируются.

## Требования

- Python 3.10 или новее.
- OAuth-токен Яндекс Диска с необходимыми разрешениями.
- Доступ к интернету.

## Установка

### Linux / macOS / WSL

Из корневой папки проекта выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Если виртуальное окружение уже создано, повторно создавать его не нужно.

### Windows PowerShell

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Настройка

1. Создайте файл `.env` на основе `.env.example`.
2. Укажите путь к существующей локальной папке.
3. Укажите имя резервной папки на Яндекс Диске.
4. Укажите свой OAuth-токен.
5. Настройте интервал синхронизации и путь к журналу.

Пример настроек:

```dotenv
LOCAL_FOLDER=./sync_folder
REMOTE_FOLDER=skillbox_backup
YANDEX_TOKEN=вставьте_сюда_свой_OAuth_токен
SYNC_INTERVAL=30
LOG_FILE=sync.log
```

Получить токен можно через инструмент Яндекс Диска: https://yandex.ru/dev/disk/poligon/

**Важно:** файл `.env` содержит секретный токен. Не публикуйте его и не добавляйте в Git. Для репозитория предназначен файл `.env.example` без настоящего токена.

## Запуск

Активируйте виртуальное окружение, перейдите в папку с `main.py` и выполните:

```bash
python main.py
```

Программа выполняет первую синхронизацию сразу после запуска, а затем повторяет её через количество секунд, указанное в `SYNC_INTERVAL`.

Для остановки нажмите `Ctrl+C`.

## Запуск тестов

Из папки проекта выполните:

```bash
python -m py_compile main.py yandex_disk.py tests/test_sync.py
python -m unittest discover -v
```

Тесты проверяют основные сценарии синхронизации с использованием тестовых объектов, без необходимости загружать файлы в облако.

## Важно о синхронизации удалений

Локальная папка является источником истины. Если удалить файл локально, программа попытается удалить соответствующий файл из резервной папки на Яндекс Диске.

Используйте отдельную папку для резервных копий. Перед работой с важными данными проверьте программу на тестовых файлах.

## Ограничения

- Синхронизируются только файлы верхнего уровня.
- За один запрос списка ресурсов запрашивается до 1000 элементов.
- Синхронизация односторонняя: локальная папка является источником истины.
- Для работы требуется действительный OAuth-токен и подключение к интернету.
- При первом запуске облачная папка может быть приведена к содержимому локальной папки. Не используйте для резервной копии папку с единственными экземплярами важных файлов.

## Структура проекта

- `main.py` — настройки, логирование и цикл синхронизации.
- `yandex_disk.py` — взаимодействие с REST API Яндекс Диска.
- `tests/test_sync.py` — автоматические тесты синхронизации.
- `.env.example` — пример конфигурации.
- `requirements.txt` — зависимости проекта.
- `.gitignore` — файлы, которые не следует добавлять в Git.
